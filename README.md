# Learning Management System (LMS)

A web-based Learning Management System built with Python and Django, designed to manage courses, user enrollments, lessons, and user profiles effectively.

---

## 📌 Features

- **User Accounts & Roles:** User registration, authentication, and profile management (`accounts`).
- **Course Management:** Create, update, and organize courses (`courses`).
- **Lessons & Content:** Structured course lessons and learning materials (`lessons`).
- **Student Enrollments:** Course registration and tracking system (`enrollments`).
- **Dashboard:** Interactive dashboard for students and instructors (`dashboard`).
- **Admin Control:** Full management capabilities via Django's built-in Admin portal.

---

## 🛠️ Tech Stack

- **Backend Framework:** Python, Django
- **Database:** SQLite (`db.sqlite3`)
- **Frontend Templates:** HTML5, CSS3, JavaScript (Django Templates)
- **Deployment Configs:** `requirements.txt`, `runtime.txt`
